# AP Schemes for Kinetic Equations

This repository contains the source code and numerical implementations for scientific papers focused on **Asymptotic-Preserving (AP) schemes for kinetic equations**.

## Repository Structure & Publications

The repository is divided into three main folders, each corresponding to a specific research paper or project:

### 1. `LBDiscVelModel/`
* **Description:** Contains source code used for simulations in *Asymptotic Preserving Methods for the Low Mach Limit in Discrete Velocity Models Approximating Kinetic Equations* [DOI: https://doi.org/10.4208/cicp.OA-2025-0309].
* **Associated Publication:** 
  If you use this code in your research, please cite the corresponding paper:
  > G. Dimarco, A. Klar, T. Köfler, L. Pareschi, (2026). *Asymptotic Preserving Methods for the Low Mach Limit in Discrete Velocity Models Approximating Kinetic Equations*. Communications in Computational Physics, 41(2):383--414. [DOI: https://doi.org/10.4208/cicp.OA-2025-0309].

### 2. `SuppMat_SecondPaper_Codes/`
* **Description:** Contains source code used for simulations in *High-Order Asymptotic-Preserving Schemes for Kinetic Equations from Rarefied to Incompressible Regimes* [DOI: https://arxiv.org/abs/2606.28040].
* **Associated Publication:** 
  If you use this supplementary material, please cite the corresponding paper:
  > G.Dimarco, A.Klar, T.Köfler, L.Pareschi, S.Tiwari (2026). *High-Order Asymptotic-Preserving Schemes for Kinetic Equations from Rarefied to Incompressible Regimes*.  arXiv preprint, Pages. [DOI: https://arxiv.org/abs/2606.28040].
  
  
### 3. `RelaxationSystem/`
* **Description:** Contains source code used for simulations in *A relaxation system for the low-Mach limit of kinetic equations: Stability and higher order asymptotic preserving scheme* [DOI: https://arxiv.org/abs/2610.00811]
* **Associated Publication:** 
  If you use this code in your research, please cite the corresponding paper:
  > G.Dimarco, A.Klar, T.Köfler, L.Pareschi, S.Tiwari, Y.Zhou (2026). *A relaxation system for the low-Mach limit of kinetic equations: Stability and higher order asymptotic preserving scheme*. arXiv preprint, Pages. [DOI: https://arxiv.org/abs/2610.00811].
